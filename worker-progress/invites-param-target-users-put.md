# PUT /invites/{param}/target-users

## Summary

- Implemented the assigned route id `invites-param-target-users-put` as `PUT /invites/:invite_code/target-users`.
- The route is bearer-authenticated and uses the documented update authorization rule: the inviter may update; non-inviters must have `MANAGE_GUILD`.
- Spacebar still has no durable Discord target-users CSV storage or async processing job model, so the route fails closed with the same typed `501 APIErrorResponse` used by the existing target-users GET/job-status handlers after invite lookup and authorization.

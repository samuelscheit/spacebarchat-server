# Spacebar Missing Routes

This package is adapted from `spacebarchat/missing-routes`.

It generates a list of Discord routes that Spacebar does not implement. The original
tool fetched Discord and Spacebar route data remotely; this workspace package reuses
the catalogs generated by `packages/automatic-reverse-engineering` instead:

- `routes.source.catalog.json` for Spacebar routes recovered from `src/api/routes`
- `routes.userdoccers.catalog.json` for documented Discord routes
- `routes.xhyrom.catalog.json` for broad Discord client routes

The comparison is method-aware. `HEAD` and `OPTIONS` are ignored by default to avoid
auxiliary method noise; pass `--include-head-options true` to include them.

```bash
npm run build --workspace @spacebar/missing-routes
npm run start --workspace @spacebar/missing-routes
```

The default output is `packages/missing-routes/missing.json`.
